# 06: 角色管理接口

**What to build:** 具备「管理角色」权限的账户可以查看角色列表与权限点目录、新建角色、编辑自定义角色、删除未被引用的自定义角色；内置角色只读。

**Blocked by:** 01（登录闭环）

**Status:** ready-for-agent

- [ ] 角色列表返回名称、描述、权限点、引用账户数、是否内置
- [ ] 权限点目录返回 5 个固定权限点，供页面渲染勾选
- [ ] 新建与编辑角色可提交任意权限点组合；角色名重复返回 409 且不区分大小写
- [ ] 内置「系统管理员」的改名、改权限、删除请求一律被拒绝并返回明确错误码
- [ ] 删除仍被账户引用的角色被拒绝并返回引用账户数；未被引用可正常删除
- [ ] 拥有「管理账户」但没有「管理角色」的账户可以读角色列表（用于账户页选角色），但不能写
- [ ] 后端接口测试覆盖上述每一条
