# 10: 端到端验收

**What to build:** 从全新环境启动到完整权限演练的一条龙验收：初始管理员登录、四个页面可达、只读角色生效、禁用与降权保护、历史会话归属正确。

**Blocked by:** 02（前端登录、路由守卫与身份切换）、05（账户管理页面）、07（角色管理页面）、08（历史会话归属迁移）

**Status:** ready-for-agent

- [ ] 全新环境只设置初始管理员口令即可启动，用默认用户名登录进入系统
- [ ] 未登录访问任意业务页面被送至登录页，登录后回到原目标；直接调用流式问答接口得到普通 JSON 401
- [ ] 四个页面按「知识库 / 系统设置」层级可达；旧地址自动跳转；面包屑正确
- [ ] 新建「文档只读」角色并分配给新账户后，该账户只看到文档管理，进入对话页被拒且提示无权限
- [ ] 禁用该账户后其已有令牌立即失效，重新登录提示「用户名或密码错误」
- [ ] 内置管理员角色无改名、改权限、删除入口，后端对三类请求均拒绝
- [ ] 最后一个具备账户管理能力的账户既不能被禁用，也不能被改成不含管理权限的角色集合
- [ ] 升级环境后原调试身份的会话出现在管理员历史列表
- [ ] 后端全量测试、前端测试、类型检查与构建全绿；默认测试档不依赖 Docker，集成档可单独放开
