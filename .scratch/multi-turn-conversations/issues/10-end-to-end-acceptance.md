# 10: 旧操作台下线与端到端验收

**What to build:** 多轮接口全部就位后，删除已被取代的单轮静态操作台，并跑通一条贴近真实用户的端到端链路：首问建会话 → 列表可见 → 追问 → 历史完整 → 刷新后仍在 → 删除后消失。确认没有遗留的旧单轮语义与两套互相矛盾的说法。

**涉及层次:** 静态资源清理、文档一致性检查、端到端冒烟（HTTP + SSE + 数据库）。

**Blocked by:** 01, 02, 03, 04, 05, 06, 07, 08, 09

**Status:** ready-for-agent

**Estimate:** 1–1.5 小时

- [ ] 旧单轮静态操作台已从仓库删除，仓库中不再有指向它的说明或链接
- [ ] 首问：无 `conversationId` 请求得到 `meta` 首事件；列表第一条为新建会话且高亮所需字段齐全
- [ ] 追问：携带 `conversationId` 成功追加一轮，模型上下文包含上一轮问答
- [ ] 历史：扁平消息按 `id ASC` 返回，两条消息共享 `roundId`，引用来源可展开
- [ ] 隔离：换一个 `X-User-Id` 看不到上一个用户的会话，直接访问其 id 得到 404
- [ ] 删除：软删后列表与历史均不可见，消息行仍在库中
- [ ] 异常：并发第二次提问得到 409；线程池拒绝得到 500 且留下 `FAILED` 记录
- [ ] `docs/schema.sql` 与需求文档、spec 中的字段名、错误码、事件顺序逐字一致，无第二套说法
- [ ] `mvn test` 全绿，端到端冒烟结果记录在 ticket 的 Comments 中
