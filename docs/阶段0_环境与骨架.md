## 二、技术版本决策

- **Spring Boot 3.5.16 + Spring AI 1.1.8**（BOM 管版本）：不追 Boot 4 / AI 2.0——手册定稿 3.x+1.x，且面试官最熟 Boot 3 生态。BOM 统一管理后续引入的 pgvector 驱动、POI 等版本号。
- **没用 Lombok**：JDK 21 record 够用，少一个注解处理器，代码可读性更好。

## 五、踩坑记录（重要）

1. **DeepSeek starter 启动时强校验 api-key**（不是调用时才校验）→ `application.yml` 用 `${DEEPSEEK_API_KEY:no-key-set}` 占位保证应用能起；key 永远走环境变量，不进代码库（开源红线）。
2. **沙箱环境注入 `SERVER__PORT` 覆盖 yml** → 本地由 AI 代跑时需 `--server.port=18080`；用户自己终端跑无此问题，默认 8080。
3. **本机安全策略屏蔽 wsl.exe / schtasks** → AI 无法直接操作 WSL；但 `docker.exe` 不在黑名单，可以代操作容器。
4. **安装器 `--wsl-default-data-file` 参数未生效** → vhdx 落了 C 盘，后经 Docker Desktop GUI（Settings→Resources→Advanced→Disk image location）迁移到 E 盘才可靠生效。
