# 14: 前端 route / plan / step 渲染与执行进度（P5）

**阶段:** P5 前端展示
**Blocked by:** 07（事件形状稳定后即可并行）
**Status:** ready-for-agent

**范围:** 前端消费三个新事件并展示执行进度；不改后端。

**要做的事:** 用户能看到「系统判断为复杂问题 → 计划 N 步 → 正在第 k 步 → 生成回答」的完整过程；`IRRELEVANT` 轮展示为规则提示。

**涉及文件/类:** 前端 SSE 解析、消息渲染组件、来源面板。

- [ ] 未知事件被忽略，不报错、不中断渲染
- [ ] `route` 到达时不产生可见干扰；`PLAN` 时展示「正在规划」
- [ ] `plan` 只渲染一次，展示步骤数与步骤标题；`args` 不展示
- [ ] `step` 按 `stepId` 更新单步状态与耗时；`FAILED` / `DEGRADED` / `SKIPPED` 有可区分样式
- [ ] 首个 `delta` 到达前显示执行进度，到达后切换为正文流式渲染
- [ ] `IRRELEVANT` 轮 `provider="rule"` 不展示模型名，展示为规则提示
- [ ] mock 模式下事件序列与现状一致，前端无需分支判断
- [ ] 断流或 `error` 后进度区域进入终态，不残留「运行中」

**不做什么:** 不做计划编辑；不做步骤重试按钮；不改 `meta` / `done` / `sources` 解析逻辑。
