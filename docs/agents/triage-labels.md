# Triage Labels

各 skill 用五个规范 triage 角色来交流。本文件把那些角色映射到本仓库 issue tracker 里实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库 tracker 中的标签 | 含义 |
| -------------------------- | ----------------------- | ---- |
| `needs-triage`             | `needs-triage`          | 维护者需要评估该 issue |
| `needs-info`               | `needs-info`            | 等待报告者补充信息 |
| `ready-for-agent`          | `ready-for-agent`       | 已充分定义，可交给 AFK agent |
| `ready-for-human`          | `ready-for-human`       | 需要人工实现 |
| `wontfix`                  | `wontfix`               | 不予处理 |

当某个 skill 提到某个角色（如「apply the AFK-ready triage label」）时，使用本表对应的标签字符串。

若你实际使用的词汇不同，请编辑「本仓库 tracker 中的标签」一列。
