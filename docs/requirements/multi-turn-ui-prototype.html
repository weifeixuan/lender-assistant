交互说明

真实可点

  • 点「＋ 新对话」进入草稿态，「最近」分组不新增条目；此时可直接提问。
  • 草稿态发出首问后，约 0.6 秒出现该会话，标题取首问前 20 字并高亮。
  • 发送、停止、停止/失败后的重试；展开引用来源，点击来引用联动右侧面板。
  • 侧栏切换会话；若正在流式，会先中止并弹提示。
  • 悬停会话出现删除入口，二次确认后移除；草稿态没有删除入口。
  • 顶部演示控制可跳到任一状态；复选框可隐藏需求标签。

只是静态示意

  • 全部是本地假数据，不请求后端、不写 localStorage / IndexedDB。
  • 流式为本地定时器逐字模拟，不代表真实 SSE 时序。
  • 标题截断、meta 回传、X-User-Id、接口路径均为前端模拟。
  • 刷新页面恢复初始假数据，删除与草稿均不持久化。
  • 右侧检索面板展示的是假 sources，未接检索服务。

与需求文档的已知差异

  • 真实 meta 是 SSE 首事件；原型用 0.6 秒定时器代替。
  • 真实并发 409、归属 404 属于接口层行为，原型未演示。
  • 真实 FAILED 可能发生在首 token 前（会话仍是草稿）；原型的失败演示发生在已有会话内。
