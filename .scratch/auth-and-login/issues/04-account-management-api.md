# 04: 账户管理接口

**What to build:** 具备「管理账户」权限的账户可以列出、新建、修改账户资料与角色、重置他人口令、启用或禁用账户；普通账户可以修改自己的口令。五条硬约束在接口层强制生效。

**Blocked by:** 01（登录闭环）

**Status:** done（2026-11-13 收尾回写；验证依据见文末）

- [x] 列表返回用户名、显示名、角色、状态与创建时间，按创建时间升序
- [x] 新建账户必须指定至少一个角色；用户名重复返回 409 且不区分大小写
- [x] 修改显示名与角色集合后返回更新结果
- [x] 重置他人口令后该账户全部会话失效；修改自己的口令需要旧口令，成功后仅保留当前令牌
- [x] 禁用账户后该账户全部会话立即失效
- [x] 不能禁用自己
- [x] 不能禁用、也不能通过改角色移除最后一个具备账户管理能力的账户；两个入口都校验，按操作完成后的状态判定
- [x] 口令按「最少 8 个字符、最多 72 字节」校验，超限返回 400
- [x] 改自己的口令接口只要求登录，不要求「管理账户」权限，且匹配顺序优先于按账户标识的改口令路径
- [x] 后端接口测试覆盖上述每条约束
