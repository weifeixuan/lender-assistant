# 02: 前端登录、路由守卫与身份切换

**What to build:** 未登录用户被送到登录页，登录后回到原目标页；令牌在刷新后仍有效；接口 401 时自动退出，403 时只提示无权限。前端不再伪造身份，所有请求改为携带令牌。

**Blocked by:** 01（登录闭环）

**Status:** done（2026-11-13 收尾回写；验证依据见文末）

**发版说明：** 与 01 同一发版窗口上线。

- [x] 未登录访问任意业务路由跳登录页，并记住原目标；登录成功后回到该目标
- [x] 已登录访问登录页时被送回业务首页
- [ ] 刷新浏览器后登录态保持；退出后回到登录页且令牌被清除
  - 未验证：退出与清令牌有页面层测试覆盖；浏览器刷新恢复登录态未实测
- [x] 业务接口返回 401 时清除令牌并跳登录；返回 403 时页面提示「无访问权限」但不跳登录
- [x] 登录页对三类凭据错误展示同一条「用户名或密码错误」
- [x] 所有请求与流式请求统一携带 `Authorization`，旧的固定身份常量与身份请求头注入已删除
- [x] mock 模式下可完成本地假登录并进入业务页面
- [x] 前端页面层测试、类型检查与构建通过
