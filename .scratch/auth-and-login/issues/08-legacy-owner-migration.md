# 08: 历史会话归属迁移

**What to build:** 升级已有环境后，原先挂在调试身份下的会话自动归属到初始管理员，管理员登录即可在历史列表看到它们；迁移重复执行无副作用，条件不满足时安全跳过。

**Blocked by:** 01（登录闭环）

**Status:** ready-for-agent

- [ ] 初始管理员创建成功后，历史调试身份的全部会话归属改为该管理员
- [ ] 重复重启应用不产生额外变更；已无历史数据时命中 0 行且不报错
- [ ] 初始管理员未创建成功时整段迁移跳过，只记录一条警告，不影响启动
- [ ] 迁移完成后管理员的历史会话列表包含这些会话，其他账户不可见（界面验证需 02 票）
- [ ] 迁移逻辑归属会话领域，经服务调用，不在建表脚本中执行
- [ ] 服务层单测覆盖「正常迁移 / 重复执行 / 跳过」三条路径
