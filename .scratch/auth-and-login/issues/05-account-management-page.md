# 05: 账户管理页面

**What to build:** 「系统设置 > 账户管理」页面可用：查看账户列表、新建账户并分配角色、调整资料与角色、重置口令、启用禁用；所有拒绝原因在页面上可见。

**Blocked by:** 03（侧边导航一级/二级与旧链接兼容）、04（账户管理接口）

**Status:** ready-for-agent

- [ ] 「系统设置」分组首次出现，其下「账户管理」可进入并高亮，面包屑显示「系统设置 / 账户管理」
- [ ] 列表展示用户名、显示名、角色、状态与创建时间
- [ ] 新建账户可选择多个角色；用户名重复时表单就地提示
- [ ] 可修改显示名与角色集合，保存后列表即时更新
- [ ] 可重置他人口令；可启用或禁用账户，禁用后状态即时变化
- [ ] 禁用自己、移除最后一个管理员的权限时，页面展示后端拒绝原因，不做静默失败
- [ ] 没有「管理账户」权限的账户看不到该菜单，直接访问被拒绝时显示无权限而非跳登录
- [ ] 前端页面层测试、类型检查与构建通过
