# 07: 角色管理页面

**What to build:** 「系统设置 > 角色管理」页面可用：查看角色与引用情况、新建与编辑角色并勾选权限点、删除无引用角色；内置角色只读。

**Blocked by:** 03（侧边导航一级/二级与旧链接兼容）、06（角色管理接口）

**Status:** ready-for-agent

- [ ] 「系统设置」下出现「角色管理」，进入后高亮，面包屑显示「系统设置 / 角色管理」
- [ ] 列表展示名称、描述、权限点数、引用账户数、是否内置
- [ ] 新建角色可勾选权限点；名称为空或重复时就地提示
- [ ] 编辑自定义角色的名称、描述与权限点后列表即时更新
- [ ] 内置角色没有改名、改权限、删除入口；若绕过界面请求，页面展示后端拒绝原因
- [ ] 删除仍被引用的角色时展示引用数量并阻止删除
- [ ] 没有「管理角色」权限的账户看不到该菜单；直接访问被拒绝时显示无权限
- [ ] 前端页面层测试、类型检查与构建通过
